SOFTWARE DEVELOPMENT COMPANY WEBSITE
====================================
Built for Job Sheet 02 - Web Design Level 3.

Technology:
- HTML5
- CSS3
- Bootstrap 5.3
- Minimal JavaScript (date/time + contact form alert)

Pages:
- index.html
- services.html
- projects.html
- project-detail.html
- about.html
- contact.html

How to run:
1. Copy this folder into Laragon\www\ or XAMPP\htdocs\
2. Start Apache in your local server.
3. Open the project folder in your browser.

No jQuery is used.
